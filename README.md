### Now

My own products, built after hours with AI coding agents. Closed source; the links go to live versions (in Turkish).

**[dash](https://dash.berkayboran.com)** — Self-hosted BI platform. Drag-and-drop reports, a visual query builder, questions in plain Turkish turned into queries by an LLM, MFA and role-based access. 20,000+ tests.

**[ytd](https://ytd.berkayboran.com)** — Investment simulator for the Turkish market. DCA scenarios across BIST and TEFAS with live market data.

**[BunCo](https://bunco.berkayboran.com)** — Bill splitting app for Android. React Native, offline-first, settles a group in the fewest transfers and shows each payer the IBAN to send to. APK on the site.
